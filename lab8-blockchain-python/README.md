# Лабораторная работа №8 — Блокчейн-шифрование файлов (Python + PyQt5)

**Вариант 2**: AES-256, SHA-256 + сжатие, GUI (PyQt5)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Функциональность

1. **Создание/загрузка файла** — создание текстового файла или выбор существующего
2. **Хэширование** — SHA-256 + сжатие (XOR-свёртка двух половин)
3. **Шифрование** — AES-256-CBC с сессионным ключом, защищённым мастер-ключом
4. **Блокчейн** — генезис-блок, добавление блоков, проверка целостности цепочки
5. **Расшифровка** — через мастер-ключ и данные из блокчейна
6. **Верификация** — проверка подлинности файла по хэшу в блокчейне
7. **Тест подмены** — принудительное изменение данных в блоке на один символ
8. **Экспорт** — сохранение блокчейна в JSON-файл

## Хранение данных

Блокчейн сохраняется в файл `blockchain.json` в каталоге приложения.
