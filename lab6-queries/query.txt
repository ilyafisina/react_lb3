// ---- Часть 1: Создание временной таблицы ----
// Выбираем ссылку на номенклатуру с отбором через параметр запроса

ВЫБРАТЬ
	Номенклатура.Ссылка КАК Номенклатура
ПОМЕСТИТЬ ВТ_Номенклатура
ИЗ
	Справочник.Номенклатура КАК Номенклатура
ГДЕ
	Номенклатура.Ссылка = &Номенклатура
;

// ---- Часть 2: Основной запрос с левыми соединениями ----
// Левое соединение с табличной частью "Товары" документа "Приходная накладная"
// Левое соединение с табличной частью "Товары" документа "Оказание услуг"

ВЫБРАТЬ
	ВТ_Номенклатура.Номенклатура КАК Номенклатура,
	ПриходнаяНакладнаяТовары.Ссылка КАК ПриходнаяНакладная,
	ОказаниеУслугТовары.Ссылка КАК ОказаниеУслуг
ИЗ
	ВТ_Номенклатура КАК ВТ_Номенклатура

	ЛЕВОЕ СОЕДИНЕНИЕ Документ.ПриходнаяНакладная.Товары КАК ПриходнаяНакладнаяТовары
	ПО ВТ_Номенклатура.Номенклатура = ПриходнаяНакладнаяТовары.Номенклатура

	ЛЕВОЕ СОЕДИНЕНИЕ Документ.ОказаниеУслуг.Товары КАК ОказаниеУслугТовары
	ПО ВТ_Номенклатура.Номенклатура = ОказаниеУслугТовары.Номенклатура
