# Лабораторная работа №6 — Работа с запросами (1С:Предприятие 8.5)

## Описание

Лабораторная работа выполнена с использованием **Консоли запросов** в 1С:Предприятие учебная версия 8.5.

Запрос реализует следующую логику:

1. **Временная таблица** `ВТ_Номенклатура` — содержит ссылку на номенклатуру из справочника «Номенклатура» с отбором по параметру запроса `&Номенклатура`.
2. **Левое соединение** с табличной частью «Товары» документа «Приходная накладная» — позволяет получить все приходные накладные, в которых присутствует выбранная номенклатура.
3. **Левое соединение** с табличной частью «Товары» документа «Оказание услуг» — позволяет получить все документы оказания услуг, в которых присутствует выбранная номенклатура.

## Структура запроса

Запрос состоит из двух частей (пакетный запрос):

### Часть 1 — Создание временной таблицы

Выбирается ссылка на номенклатуру из справочника `Номенклатура` и помещается во временную таблицу `ВТ_Номенклатура`. Отбор осуществляется через параметр запроса `&Номенклатура`.

### Часть 2 — Основной запрос с левыми соединениями

К временной таблице `ВТ_Номенклатура` присоединяются:

- **Левое соединение** с `Документ.ПриходнаяНакладная.Товары` — по полю `Номенклатура`. Используется именно табличная часть документа, а не сам документ.
- **Левое соединение** с `Документ.ОказаниеУслуг.Товары` — по полю `Номенклатура`. Используется именно табличная часть документа, а не сам документ.

## Параметры запроса

| Параметр        | Тип                              | Описание                                      |
|-----------------|----------------------------------|-----------------------------------------------|
| `&Номенклатура` | `СправочникСсылка.Номенклатура`  | Ссылка на элемент справочника «Номенклатура»  |

## Как использовать

1. Откройте **Консоль запросов** в 1С:Предприятие 8.5.
2. Скопируйте текст запроса из файла `query.txt`.
3. Вставьте запрос в поле ввода консоли запросов.
4. Установите параметр `Номенклатура` — выберите нужный элемент справочника «Номенклатура».
5. Нажмите **Выполнить**.

## Результат

Запрос вернёт таблицу со следующими полями:

| Поле                    | Описание                                                  |
|-------------------------|-----------------------------------------------------------|
| `Номенклатура`          | Ссылка на элемент справочника «Номенклатура»              |
| `ПриходнаяНакладная`    | Ссылка на документ «Приходная накладная» (или NULL)        |
| `ОказаниеУслуг`         | Ссылка на документ «Оказание услуг» (или NULL)            |
