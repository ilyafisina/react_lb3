# Пошаговая инструкция: «Заявка на транспорт» в 1С:Предприятие 8.5

Всё делается в **Конфигураторе** (меню «Конфигурация → Открыть конфигурацию»).

---

## 1. Справочники

Для каждого справочника: **правой кнопкой** по ветке «Справочники» в дереве конфигурации → **Добавить**.

| № | Имя | Синоним | Длина кода | Длина наименования |
|---|-----|---------|------------|--------------------|
| 1 | `ТранспортныеСредства` | Транспортные средства | 9 | 100 |
| 2 | `ФизическиеЛица` | Физические лица | 9 | 150 |
| 3 | `Номенклатура` | Номенклатура | 9 | 150 |
| 4 | `Водители` | Водители | 9 | 150 |
| 5 | `Грузчики` | Грузчики | 9 | 150 |
| 6 | `Контрагенты` | Контрагенты | 9 | 150 |
| 7 | `КонтактныеЛица` | Контактные лица | 9 | 150 |

**Для каждого справочника:**
1. Дважды щёлкните по созданному справочнику → откроется окно редактирования.
2. Вкладка **«Основные»** — задайте **Имя** и **Синоним** из таблицы.
3. Вкладка **«Данные»** — установите **Длину кода** и **Длину наименования**.
4. Нажмите **«Закрыть»**.

> Справочники простые — без дополнительных реквизитов. Достаточно стандартных полей «Код» и «Наименование».

---

## 2. Перечисление «Статусы заявки»

1. Правой кнопкой по ветке **«Перечисления»** → **Добавить**.
2. **Имя:** `СтатусыЗаявки`, **Синоним:** `Статусы заявки`.
3. Перейдите на вкладку **«Данные»** и добавьте значения:

| № | Имя значения | Синоним |
|---|-------------|---------|
| 1 | `НеВыехали` | Не выехали |
| 2 | `ВДорогеККлиенту` | В дороге к клиенту |
| 3 | `УКлиента` | У клиента |
| 4 | `ВДорогеОбратно` | В дороге обратно |
| 5 | `Обработан` | Обработан |

4. Нажмите **«Закрыть»**.

---

## 3. Регистр сведений «Занятость машин»

> Регистр создаём **перед** документом, потому что документ будет на него ссылаться.

1. Правой кнопкой по ветке **«Регистры сведений»** → **Добавить**.
2. **Имя:** `ЗанятостьМашин`, **Синоним:** `Занятость машин`.
3. Вкладка **«Основные»**:
   - **Периодичность:** `В пределах дня` (период — 1 день).
   - **Режим записи:** `Подчинение регистратору`.
4. Вкладка **«Данные»**:
   - **Измерения** — добавьте:
     - Имя: `Машина`, Тип: `СправочникСсылка.ТранспортныеСредства`.
   - **Ресурсы** — добавьте:
     - Имя: `Занята`, Тип: `Булево`.
5. Вкладка **«Регистраторы»**:
   - Пока оставьте пустым (добавим после создания документа).
6. Нажмите **«Закрыть»**.

## 4. Документ «Заявка на транспорт»

### 4.1. Создание документа

1. Правой кнопкой по ветке **«Документы»** → **Добавить**.
2. **Имя:** `ЗаявкаНаТранспорт`, **Синоним:** `Заявка на транспорт`.

### 4.2. Реквизиты (вкладка «Данные»)

Добавьте реквизиты шапки:

| № | Имя | Тип | Примечание |
|---|-----|-----|------------|
| 1 | `Контрагент` | `СправочникСсылка.Контрагенты` | |
| 2 | `КонтактноеЛицо` | `СправочникСсылка.КонтактныеЛица` | |
| 3 | `ДатаДоставки` | `Дата` | Состав даты: «Дата» |
| 4 | `Машина` | `СправочникСсылка.ТранспортныеСредства` | Выбор свободных — см. п. 4.5 |
| 5 | `Водитель` | `СправочникСсылка.Водители` | |
| 6 | `Статус` | `ПеречислениеСсылка.СтатусыЗаявки` | |
| 7 | `Километраж` | `Число` (15, 3) | Длина 15, Точность 3 |

### 4.3. Табличная часть «Грузчики»

1. В разделе **«Табличные части»** нажмите **«Добавить»** табличную часть.
2. **Имя:** `Грузчики`.
3. Добавьте реквизит табличной части:
   - Имя: `Грузчик`, Тип: `СправочникСсылка.Грузчики`.

### 4.4. Табличная часть «Товары»

1. Добавьте ещё одну табличную часть: **Имя:** `Товары`.
2. Добавьте реквизиты:

| № | Имя | Тип |
|---|-----|-----|
| 1 | `Номенклатура` | `СправочникСсылка.Номенклатура` |
| 2 | `Количество` | `Число` (15, 3) |
| 3 | `Цена` | `Число` (15, 2) |
| 4 | `Сумма` | `Число` (15, 2) |

### 4.5. Привязка регистратора

После создания документа вернитесь в регистр сведений `ЗанятостьМашин`:
1. Вкладка **«Регистраторы»** → поставьте галочку напротив `ЗаявкаНаТранспорт`.

### 4.6. Модуль объекта документа

Правый клик по документу `ЗаявкаНаТранспорт` → **«Открыть модуль объекта»** (или через вкладку **«Прочее»** → кнопка **«Модуль объекта»**).

Вставьте следующий код:

```1c
// =============================================================
// МОДУЛЬ ОБЪЕКТА документа «Заявка на транспорт»
// =============================================================

Процедура ОбработкаПроведения(Отказ, РежимПроведения)
	
	// Записываем в регистр «Занятость машин»
	Движения.ЗанятостьМашин.Записывать = Истина;
	
	Движение = Движения.ЗанятостьМашин.Добавить();
	Движение.Период  = ДатаДоставки;
	Движение.Машина   = Машина;
	Движение.Занята   = Истина;
	
КонецПроцедуры

Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	
	// Подсчитываем общую сумму документа
	ОбщаяСумма = 0;
	Для Каждого СтрокаТовара Из Товары Цикл
		ОбщаяСумма = ОбщаяСумма + СтрокаТовара.Сумма;
	КонецЦикла;
	
	// Если сумма больше 1000 — выдаём сообщение
	Если ОбщаяСумма > 1000 Тогда
		Сообщить("Возможна бесплатная доставка");
	КонецЕсли;
	
КонецПроцедуры
```

## 5. Форма документа «Заявка на транспорт»

### 5.1. Создание формы

1. Двойной клик по документу `ЗаявкаНаТранспорт`.
2. Вкладка **«Формы»** → нажмите кнопку со значком **«+»** (или лупу) рядом с полем **«Форма документа»**.
3. В появившемся конструкторе выберите **«Создать новую форму документа»**, нажмите **«Готово»**.

### 5.2. Удаление всех элементов с формы

1. Откройте созданную форму.
2. В верхней левой части редактора формы вы увидите дерево **«Элементы формы»**.
3. Выделите **все элементы** (Ctrl+A или по одному).
4. Нажмите **Delete** (или правой кнопкой → «Удалить»).
5. Форма теперь пустая.

### 5.3. Программный вывод реквизитов на форму (модуль формы)

Перейдите в модуль формы: в редакторе формы внизу вкладка **«Модуль»**.

Вставьте следующий код:

```1c
// =============================================================
// МОДУЛЬ ФОРМЫ документа «Заявка на транспорт»
// =============================================================

&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	
	// === Группа «Номер и Дата» на одной строке (горизонтальная) ===
	
	ГруппаШапка = Элементы.Добавить("ГруппаНомерДата", Тип("ГруппаФормы"), ЭтаФорма);
	ГруппаШапка.Вид = ВидГруппыФормы.ОбычнаяГруппа;
	ГруппаШапка.Группировка = ГруппировкаПодчиненныхЭлементовФормы.ГоризонтальнаяЕслиВозможно;
	ГруппаШапка.ОтображатьЗаголовок = Ложь;
	
	// Номер
	ЭлементНомер = Элементы.Добавить("Номер", Тип("ПолеФормы"), ГруппаШапка);
	ЭлементНомер.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементНомер.ПутьКДанным = "Объект.Номер";
	ЭлементНомер.Заголовок = "Номер";
	
	// Дата
	ЭлементДата = Элементы.Добавить("Дата", Тип("ПолеФормы"), ГруппаШапка);
	ЭлементДата.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементДата.ПутьКДанным = "Объект.Дата";
	ЭлементДата.Заголовок = "Дата";
	
	// === Реквизиты шапки ===
	
	// Контрагент
	ЭлементКонтрагент = Элементы.Добавить("Контрагент", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементКонтрагент.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементКонтрагент.ПутьКДанным = "Объект.Контрагент";
	ЭлементКонтрагент.Заголовок = "Контрагент";
	
	// Контактное лицо
	ЭлементКЛ = Элементы.Добавить("КонтактноеЛицо", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементКЛ.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементКЛ.ПутьКДанным = "Объект.КонтактноеЛицо";
	ЭлементКЛ.Заголовок = "Контактное лицо";
	
	// Дата доставки
	ЭлементДД = Элементы.Добавить("ДатаДоставки", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементДД.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементДД.ПутьКДанным = "Объект.ДатаДоставки";
	ЭлементДД.Заголовок = "Дата доставки";
	
	// Машина (+ обработчик проверки занятости при изменении)
	ЭлементМашина = Элементы.Добавить("Машина", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементМашина.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементМашина.ПутьКДанным = "Объект.Машина";
	ЭлементМашина.Заголовок = "Машина";
	ЭлементМашина.УстановитьДействие("ПриИзменении", "МашинаПриИзменении");
	
	// Водитель
	ЭлементВодитель = Элементы.Добавить("Водитель", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементВодитель.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементВодитель.ПутьКДанным = "Объект.Водитель";
	ЭлементВодитель.Заголовок = "Водитель";
	
	// Статус
	ЭлементСтатус = Элементы.Добавить("Статус", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементСтатус.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементСтатус.ПутьКДанным = "Объект.Статус";
	ЭлементСтатус.Заголовок = "Статус";
	
	// Километраж
	ЭлементКМ = Элементы.Добавить("Километраж", Тип("ПолеФормы"), ЭтаФорма);
	ЭлементКМ.Вид = ВидПоляФормы.ПолеВвода;
	ЭлементКМ.ПутьКДанным = "Объект.Километраж";
	ЭлементКМ.Заголовок = "Километраж";
	
	// === Вкладки «Грузчики» и «Товары» (страницы формы) ===
	
	СтраницыТаблиц = Элементы.Добавить("СтраницыТаблиц", Тип("ГруппаФормы"), ЭтаФорма);
	СтраницыТаблиц.Вид = ВидГруппыФормы.Страницы;
	
	// --- Страница «Грузчики» ---
	
	СтраницаГрузчики = Элементы.Добавить("СтраницаГрузчики", Тип("ГруппаФормы"), СтраницыТаблиц);
	СтраницаГрузчики.Вид = ВидГруппыФормы.Страница;
	СтраницаГрузчики.Заголовок = "Грузчики";
	
	ТаблицаГрузчики = Элементы.Добавить("Грузчики", Тип("ТаблицаФормы"), СтраницаГрузчики);
	ТаблицаГрузчики.ПутьКДанным = "Объект.Грузчики";
	ТаблицаГрузчики.Заголовок = "Грузчики";
	
	КолонкаГрузчик = Элементы.Добавить("ГрузчикиГрузчик", Тип("ПолеФормы"), ТаблицаГрузчики);
	КолонкаГрузчик.Вид = ВидПоляФормы.ПолеВвода;
	КолонкаГрузчик.ПутьКДанным = "Объект.Грузчики.Грузчик";
	КолонкаГрузчик.Заголовок = "Грузчик";
	
	// --- Страница «Товары» ---
	
	СтраницаТовары = Элементы.Добавить("СтраницаТовары", Тип("ГруппаФормы"), СтраницыТаблиц);
	СтраницаТовары.Вид = ВидГруппыФормы.Страница;
	СтраницаТовары.Заголовок = "Товары";
	
	ТаблицаТовары = Элементы.Добавить("Товары", Тип("ТаблицаФормы"), СтраницаТовары);
	ТаблицаТовары.ПутьКДанным = "Объект.Товары";
	ТаблицаТовары.Заголовок = "Товары";
	
	КолонкаНоменклатура = Элементы.Добавить("ТоварыНоменклатура", Тип("ПолеФормы"), ТаблицаТовары);
	КолонкаНоменклатура.Вид = ВидПоляФормы.ПолеВвода;
	КолонкаНоменклатура.ПутьКДанным = "Объект.Товары.Номенклатура";
	КолонкаНоменклатура.Заголовок = "Номенклатура";
	
	КолонкаКоличество = Элементы.Добавить("ТоварыКоличество", Тип("ПолеФормы"), ТаблицаТовары);
	КолонкаКоличество.Вид = ВидПоляФормы.ПолеВвода;
	КолонкаКоличество.ПутьКДанным = "Объект.Товары.Количество";
	КолонкаКоличество.Заголовок = "Количество";
	КолонкаКоличество.УстановитьДействие("ПриИзменении", "ТоварыКоличествоПриИзменении");
	
	КолонкаЦена = Элементы.Добавить("ТоварыЦена", Тип("ПолеФормы"), ТаблицаТовары);
	КолонкаЦена.Вид = ВидПоляФормы.ПолеВвода;
	КолонкаЦена.ПутьКДанным = "Объект.Товары.Цена";
	КолонкаЦена.Заголовок = "Цена";
	КолонкаЦена.УстановитьДействие("ПриИзменении", "ТоварыЦенаПриИзменении");
	
	КолонкаСумма = Элементы.Добавить("ТоварыСумма", Тип("ПолеФормы"), ТаблицаТовары);
	КолонкаСумма.Вид = ВидПоляФормы.ПолеВвода;
	КолонкаСумма.ПутьКДанным = "Объект.Товары.Сумма";
	КолонкаСумма.Заголовок = "Сумма";
	
КонецПроцедуры

// === Проверка занятости машины при ручном выборе/изменении ===
&НаКлиенте
Процедура МашинаПриИзменении(Элемент)
	
	Если ЗначениеЗаполнено(Объект.Машина) И ЗначениеЗаполнено(Объект.ДатаДоставки) Тогда
		МашинаЗанята = ПроверитьЗанятостьМашины(Объект.Машина, Объект.ДатаДоставки);
		Если МашинаЗанята Тогда
			ПоказатьПредупреждение(, "Данная машина занята на " + Формат(Объект.ДатаДоставки, "ДЛФ=Д") + "! Выберите другую.");
			Объект.Машина = Неопределено;
		КонецЕсли;
	КонецЕсли;
	
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПроверитьЗанятостьМашины(Машина, ДатаПроверки)
	
	Запрос = Новый Запрос;
	Запрос.Текст = 
	"ВЫБРАТЬ
	|	Занятость.Занята КАК Занята
	|ИЗ
	|	РегистрСведений.ЗанятостьМашин.СрезПоследних(&Дата, Машина = &Машина) КАК Занятость";
	
	Запрос.УстановитьПараметр("Дата", ДатаПроверки);
	Запрос.УстановитьПараметр("Машина", Машина);
	
	Результат = Запрос.Выполнить();
	Выборка = Результат.Выбрать();
	
	Если Выборка.Следующий() Тогда
		Возврат Выборка.Занята = Истина;
	КонецЕсли;
	
	Возврат Ложь;
	
КонецФункции

// === Автоматический расчёт суммы при изменении количества или цены ===
&НаКлиенте
Процедура ТоварыКоличествоПриИзменении(Элемент)
	
	ТекущаяСтрока = Элементы.Товары.ТекущиеДанные;
	Если ТекущаяСтрока <> Неопределено Тогда
		ТекущаяСтрока.Сумма = ТекущаяСтрока.Количество * ТекущаяСтрока.Цена;
	КонецЕсли;
	
КонецПроцедуры

&НаКлиенте
Процедура ТоварыЦенаПриИзменении(Элемент)
	
	ТекущаяСтрока = Элементы.Товары.ТекущиеДанные;
	Если ТекущаяСтрока <> Неопределено Тогда
		ТекущаяСтрока.Сумма = ТекущаяСтрока.Количество * ТекущаяСтрока.Цена;
	КонецЕсли;
	
КонецПроцедуры
```

> **Важно:** Не забудьте назначить обработчик `ПриСозданииНаСервере` в свойствах формы (раздел «События»), как описано в п. 5.2.

## Итоговая структура в дереве конфигурации

```
Конфигурация
├── Справочники
│   ├── ТранспортныеСредства
│   ├── ФизическиеЛица
│   ├── Номенклатура
│   ├── Водители
│   ├── Грузчики
│   ├── Контрагенты
│   └── КонтактныеЛица
├── Перечисления
│   └── СтатусыЗаявки (НеВыехали, ВДорогеККлиенту, УКлиента, ВДорогеОбратно, Обработан)
├── Документы
│   └── ЗаявкаНаТранспорт
│       ├── Реквизиты: Контрагент, КонтактноеЛицо, ДатаДоставки, Машина, Водитель, Статус, Километраж
│       ├── ТЧ «Грузчики»: Грузчик
│       ├── ТЧ «Товары»: Номенклатура, Количество, Цена, Сумма
│       ├── Модуль объекта: проведение + проверка суммы > 1000
│       └── Форма документа: программный вывод элементов
└── Регистры сведений
    └── ЗанятостьМашин (период: день, регистратор: ЗаявкаНаТранспорт)
        ├── Измерение: Машина
        └── Ресурс: Занята (Булево)
```
