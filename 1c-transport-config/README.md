# Пошаговая инструкция: «Заявка на транспорт» в 1С:Предприятие 8.5

Всё делается в **Конфигураторе** (меню «Конфигурация → Открыть конфигурацию»).

---

## 1. Справочники

Для каждого справочника: **правой кнопкой** по ветке «Справочники» в дереве конфигурации → **Добавить**.

| № | Имя | Синоним | Длина кода | Длина наименования |
|---|-----|---------|------------|--------------------|
| 1 | `ТранспортныеСредства` | Транспортные средства | 9 | 100 |
| 2 | `ФизическиеЛица` | Физические лица | 9 | 150 |
| 3 | `Номенклатура` | Номенклатура | 9 | 150 |
| 4 | `Водители` | Водители | 9 | 150 |
| 5 | `Грузчики` | Грузчики | 9 | 150 |
| 6 | `Контрагенты` | Контрагенты | 9 | 150 |
| 7 | `КонтактныеЛица` | Контактные лица | 9 | 150 |

**Для каждого справочника:**
1. Дважды щёлкните по созданному справочнику → откроется окно редактирования.
2. Вкладка **«Основные»** — задайте **Имя** и **Синоним** из таблицы.
3. Вкладка **«Данные»** — установите **Длину кода** и **Длину наименования**.
4. Нажмите **«Закрыть»**.

> Справочники простые — без дополнительных реквизитов. Достаточно стандартных полей «Код» и «Наименование».

## 2. Перечисление «Статусы заявки»

1. Правой кнопкой по ветке **«Перечисления»** → **Добавить**.
2. **Имя:** `СтатусыЗаявки`, **Синоним:** `Статусы заявки`.
3. Перейдите на вкладку **«Данные»** и добавьте значения:

| № | Имя значения | Синоним |
|---|-------------|---------|
| 1 | `НеВыехали` | Не выехали |
| 2 | `ВДорогеККлиенту` | В дороге к клиенту |
| 3 | `УКлиента` | У клиента |
| 4 | `ВДорогеОбратно` | В дороге обратно |
| 5 | `Обработан` | Обработан |

4. Нажмите **«Закрыть»**.

---

## 3. Регистр сведений «Занятость машин»

> Регистр создаём **перед** документом, потому что документ будет на него ссылаться.

1. Правой кнопкой по ветке **«Регистры сведений»** → **Добавить**.
2. **Имя:** `ЗанятостьМашин`, **Синоним:** `Занятость машин`.
3. Вкладка **«Основные»**:
   - **Периодичность:** `В пределах дня` (период — 1 день).
   - **Режим записи:** `Подчинение регистратору`.
4. Вкладка **«Данные»**:
   - **Измерения** — добавьте:
     - Имя: `Машина`, Тип: `СправочникСсылка.ТранспортныеСредства`.
   - **Ресурсы** — добавьте:
     - Имя: `Занята`, Тип: `Булево`.
5. Вкладка **«Регистраторы»**:
   - Пока оставьте пустым (добавим после создания документа).
6. Нажмите **«Закрыть»**.

## 4. Документ «Заявка на транспорт»

### 4.1. Создание документа

1. Правой кнопкой по ветке **«Документы»** → **Добавить**.
2. **Имя:** `ЗаявкаНаТранспорт`, **Синоним:** `Заявка на транспорт`.

### 4.2. Реквизиты (вкладка «Данные»)

Добавьте реквизиты шапки:

| № | Имя | Тип | Примечание |
|---|-----|-----|------------|
| 1 | `Контрагент` | `СправочникСсылка.Контрагенты` | |
| 2 | `КонтактноеЛицо` | `СправочникСсылка.КонтактныеЛица` | |
| 3 | `ДатаДоставки` | `Дата` | Состав даты: «Дата» |
| 4 | `Машина` | `СправочникСсылка.ТранспортныеСредства` | Выбор свободных — см. п. 4.5 |
| 5 | `Водитель` | `СправочникСсылка.Водители` | |
| 6 | `Статус` | `ПеречислениеСсылка.СтатусыЗаявки` | |
| 7 | `Километраж` | `Число` (15, 3) | Длина 15, Точность 3 |

### 4.3. Табличная часть «Грузчики»

1. В разделе **«Табличные части»** нажмите **«Добавить»** табличную часть.
2. **Имя:** `Грузчики`.
3. Добавьте реквизит табличной части:
   - Имя: `Грузчик`, Тип: `СправочникСсылка.Грузчики`.

### 4.4. Табличная часть «Товары»

1. Добавьте ещё одну табличную часть: **Имя:** `Товары`.
2. Добавьте реквизиты:

| № | Имя | Тип |
|---|-----|-----|
| 1 | `Номенклатура` | `СправочникСсылка.Номенклатура` |
| 2 | `Количество` | `Число` (15, 3) |
| 3 | `Цена` | `Число` (15, 2) |
| 4 | `Сумма` | `Число` (15, 2) |

### 4.5. Привязка регистратора

После создания документа вернитесь в регистр сведений `ЗанятостьМашин`:
1. Вкладка **«Регистраторы»** → поставьте галочку напротив `ЗаявкаНаТранспорт`.

### 4.6. Модуль объекта документа

Правый клик по документу `ЗаявкаНаТранспорт` → **«Открыть модуль объекта»** (или через вкладку **«Прочее»** → кнопка **«Модуль объекта»**).

Вставьте следующий код:

```1c
// =============================================================
// МОДУЛЬ ОБЪЕКТА документа «Заявка на транспорт»
// =============================================================

Процедура ОбработкаПроведения(Отказ, РежимПроведения)
	
	// Записываем в регистр «Занятость машин»
	Движения.ЗанятостьМашин.Записывать = Истина;
	
	Движение = Движения.ЗанятостьМашин.Добавить();
	Движение.Период  = ДатаДоставки;
	Движение.Машина   = Машина;
	Движение.Занята   = Истина;
	
КонецПроцедуры

Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	
	// Подсчитываем общую сумму документа
	ОбщаяСумма = 0;
	Для Каждого СтрокаТовара Из Товары Цикл
		ОбщаяСумма = ОбщаяСумма + СтрокаТовара.Сумма;
	КонецЦикла;
	
	// Если сумма больше 1000 — выдаём сообщение
	Если ОбщаяСумма > 1000 Тогда
		Сообщить("Возможна бесплатная доставка");
	КонецЕсли;
	
КонецПроцедуры
```

## 5. Форма документа «Заявка на транспорт»

### 5.1. Создание формы

1. Двойной клик по документу `ЗаявкаНаТранспорт`.
2. Вкладка **«Формы»** → нажмите кнопку со значком **«+»** (или лупу) рядом с полем **«Форма документа»**.
3. В появившемся конструкторе выберите **«Создать новую форму документа»**, нажмите **«Готово»**.

### 5.2. Удаление всех элементов с формы

1. Откройте созданную форму.
2. В верхней левой части редактора формы вы увидите дерево **«Элементы формы»**.
3. Выделите **все элементы** (Ctrl+A или по одному).
4. Нажмите **Delete** (или правой кнопкой → «Удалить»).
5. Форма теперь пустая.

```1c
	КолонкаКоличество.ПутьКДанным = "Объект.Товары.Количество";

// Автоматический расчёт суммы при изменении количества или цены

	ТекущаяСтрока = Элементы.Товары.ТекущиеДанные;

		ТекущаяСтрока.Сумма = ТекущаяСтрока.Количество * ТекущаяСтрока.Цена;

КонецПроцедуры

&НаКлиенте
Процедура ТоварыЦенаПриИзменении(Элемент)
	
	ТекущаяСтрока = Элементы.Товары.ТекущиеДанные;
	Если ТекущаяСтрока <> Неопределено Тогда
		ТекущаяСтрока.Сумма = ТекущаяСтрока.Количество * ТекущаяСтрока.Цена;
	КонецЕсли;
	
КонецПроцедуры
```

> **Важно:** После вставки кода модуля формы, нужно назначить обработчики событий для колонок «Количество» и «Цена» в таблице «Товары». Для этого:
> 1. Перейдите в модуль формы.
> 2. В процедуре `ПриСозданииНаСервере` после создания колонок `КолонкаКоличество` и `КолонкаЦена` добавьте привязку обработчиков:
>
> ```1c
> КолонкаКоличество.УстановитьДействие("ПриИзменении", "ТоварыКоличествоПриИзменении");
> КолонкаЦена.УстановитьДействие("ПриИзменении", "ТоварыЦенаПриИзменении");
> ```
>
> Вставьте эти две строки **сразу после** создания соответствующих колонок в `ПриСозданииНаСервере`.

## 6. Выбор свободных машин (фильтрация по регистру)

Чтобы в поле «Машина» документа показывались **только свободные** транспортные средства на дату документа, нужно добавить обработчик события формы.

Добавьте в **модуль формы** следующий код:

```1c
// Обработчик начала выбора машины — фильтрует по регистру «Занятость машин»
&НаКлиенте
Процедура МашинаНачалоВыбора(Элемент, ДанныеВыбора, СтандартнаяОбработка)
	
	СтандартнаяОбработка = Ложь;
	ДанныеВыбора = ПолучитьСвободныеМашины(Объект.ДатаДоставки);
	
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьСвободныеМашины(ДатаПроверки)
	
	Запрос = Новый Запрос;
	Запрос.Текст = 
	"ВЫБРАТЬ
	|	ТС.Ссылка КАК Машина
	|ИЗ
	|	Справочник.ТранспортныеСредства КАК ТС
	|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ЗанятостьМашин.СрезПоследних(&Дата, ) КАК Занятость
	|		ПО ТС.Ссылка = Занятость.Машина
	|ГДЕ
	|	(Занятость.Занята ЕСТЬ NULL
	|		ИЛИ Занятость.Занята = ЛОЖЬ)";
	
	Запрос.УстановитьПараметр("Дата", ДатаПроверки);
	
	Результат = Запрос.Выполнить();
	
	СписокВыбора = Новый СписокЗначений;
	Выборка = Результат.Выбрать();
	Пока Выборка.Следующий() Цикл
		СписокВыбора.Добавить(Выборка.Машина);
	КонецЦикла;
	
	Возврат СписокВыбора;
	
КонецФункции
```

Также в `ПриСозданииНаСервере` добавьте привязку обработчика для элемента «Машина»:

```1c
ЭлементМашина.УстановитьДействие("НачалоВыбора", "МашинаНачалоВыбора");
```

## Порядок создания (рекомендуемый)

1. Все 7 справочников
2. Перечисление «Статусы заявки»
3. Регистр сведений «Занятость машин» (без регистратора пока)
4. Документ «Заявка на транспорт» (реквизиты + табличные части)
5. Вернуться в регистр → добавить регистратор «Заявка на транспорт»
